# TrendMiner Interface

Python control package for the TrendMiner API.

## Installation

Install the latest release ([`v1.6.0a2`](https://github.com/TrendMinerCS/trendminer-interface/releases/tag/v1.6.0a2)) directly from its wheel:

```
pip install https://github.com/TrendMinerCS/trendminer-interface/releases/download/v1.6.0a2/trendminer_interface-1.6.0.a2-py3-none-any.whl
```

New here? Start with **[Getting started](https://trendminercs.github.io/trendminer-interface/getting-started/index.md)**.

## Reference

- **[Interface tree](https://trendminercs.github.io/trendminer-interface/reference/interface-tree/index.md)** — the full interface tree; every namespace lists its methods and return types, with links through to the detailed pages.
- **Objects & Types** — the `TrendMinerClient`, the interface (facade) classes, and the classes their methods return (objects, definitions, containers, exceptions), each showing its public attributes, properties and methods.

## For LLMs

Using an AI assistant with this SDK? The most robust way to get started with most LLMs is to download **`llms-full.txt`** — the full guides and API reference in a single file — and upload it to your assistant as a file attachment:

[Download llms-full.txt](https://trendminercs.github.io/trendminer-interface/llms-full.txt)

Uploading works with any chat assistant, including those that cannot browse the web or that only read part of a long page. The file is large, so a large-context model gives the best results. Download it again after upgrading to a new release.

If your tool can fetch URLs itself (e.g. coding agents), you can instead point it at **`llms.txt`**: a concise, linked index of the documentation that follows the [llms.txt](https://llmstxt.org/) convention:

```
https://trendminercs.github.io/trendminer-interface/llms.txt
```
