## trendminer_interface.objects.TrendHubViewTileConfiguration

Configuration for TrendHub view tile

Attributes:

| Name                   | Type   | Description                                                    |
| ---------------------- | ------ | -------------------------------------------------------------- |
| `show_title`           | `bool` | Whether to show tile title                                     |
| `show_context_items`   | `bool` | Whether to show context items on the view                      |
| `show_timeframe`       | `bool` | Whether to show the timeframe of the view                      |
| `show_component_names` | `bool` | Whether to show the component names as labels                  |
| `show_legend`          | `bool` | Whether to show the point color legend for a scatter plot view |
