    ContextEnumerationFieldFilter

    trendminer_interface.objects.ContextEnumerationFieldFilter dataclass

    Filter on context enumeration field values

    Attributes:

    Name Type Description
    field ContextField

    The context field on which to filter. Must be of 'enumeration' type.
    values list[str] | None

    List of values to filter on. Must be values allowed by the field.
    mode {'empty', 'not empty'} | None

    When not None, filter on empty/non-empty field instead of specific values.

    field instance-attribute 

    field: ContextField

    values instance-attribute 

    values: list[str] | None

    mode instance-attribute 

    mode: EmptyMode | None
