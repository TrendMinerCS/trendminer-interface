# `client.context`

## trendminer_interface.\_client.context.ContextFacade

Facade for interacting with ContextHub and context items

### view

```
view: ContextHubViewFacade
```

Facade for getting saved ContextHub views

### item

```
item: ContextItemFacade
```

Facade for creating, updating and deleting context items

### type

```
type: ContextTypeFacade
```

Facade for retrieving and creating context types

### field

```
field: ContextFieldFacade
```

Facade for retrieving and creating context fields

### workflow

```
workflow: ContextWorkflowFacade
```

Facade for retrieving and creating context workflows

### filter

```
filter: ContextFilterFacade
```

Facade for creating filters to filter context items when retrieving them
